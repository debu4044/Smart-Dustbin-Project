# Version 4 - Intelligent Waste Analysis

## Overview

This is the most advanced implementation of the Smart Dustbin project.

It introduces a finite state machine, improved area-based fill estimation, grouped sensor averaging, and a refined software architecture.

---

## Key Innovations

- Finite State Machine
- Area-Based Fill Estimation
- Grouped Radar Sampling
- Noise Reduction
- Reset Mechanism
- Modular OOP Design
