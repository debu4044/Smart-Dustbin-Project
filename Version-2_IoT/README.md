# Version 2 - IoT Smart Dustbin

## Overview

This version extends the original hardware implementation by integrating IoT services for remote monitoring and notifications.

The dustbin can now communicate over Wi-Fi, upload sensor data to the cloud, and notify users when the bin is full.

---

## New Features

- Blynk Dashboard
- ThingSpeak Cloud Logging
- Twilio SMS Alerts
- Wi-Fi Connectivity
- Remote Lid Control

---

## Technologies

- ESP8266
- Blynk
- ThingSpeak
- Twilio API
