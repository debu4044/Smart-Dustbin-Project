# Version 3 - OOP Based Smart Dustbin Simulation

## Overview

This version focuses on improving the software architecture of the Smart Dustbin.

The project was migrated to Wokwi and rewritten using Object-Oriented Programming to improve modularity and scalability.

---

## Major Changes

- Sensor Class
- Three Ultrasonic Sensors
- Rotating Radar Sensor
- Smooth Servo Motion
- Buzzer Alerts

---

## Algorithm

1. Detect user.

2. Open lid.

3. Measure waste height.

4. Rotate scanning sensor.

5. Estimate fill percentage.

6. Trigger fill alert.

---

## Why Wokwi?

Additional hardware components were unavailable during development.

Wokwi allowed rapid experimentation with advanced algorithms before physical implementation.

---

## Improvements over Version 2

- Better software architecture
- Modular design
- Advanced fill scanning
- Trigonometric estimation
